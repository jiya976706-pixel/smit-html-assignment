Frequently Asked Questions

What is HTML?

HTML stands for HyperText Markup Language. It is used to structure content on web pages.

What is the purpose of the audio element?

The audio element is used to add sound or audio files to a web page.

What is the purpose of the video element?

The video element allows a video file to be displayed and played directly on a web page.

Why are relative media paths used?

Relative paths allow media files to be stored inside the project folder and accessed using their location relative to the HTML file.
